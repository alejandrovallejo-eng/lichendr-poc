Propósito
: Gestionar los sitios de muestreo dentro de un proyecto.

Datos que administra
- `Site` (id, projectId, coordenadas, altitud, nombre)

Responsabilidades
- Registrar y mostrar sitios
- Vincular sitios a proyectos

Pendiente
- Geocoding y validaciones de coordenadas
- Sincronización con backend
