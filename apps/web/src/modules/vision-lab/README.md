# Laboratorio IA

Esta vista experimental permite probar la segmentación asistida de líquenes completamente en el navegador con SlimSAM.

## Objetivo

Evaluar si el modelo puede proponer máscaras útiles a partir de puntos positivos y negativos sobre fotografías locales.

## Notas de privacidad

- La imagen se procesa localmente en el navegador.
- El modelo se descarga en la primera carga del laboratorio.
- La vista no sube imágenes ni máscaras a Supabase.
