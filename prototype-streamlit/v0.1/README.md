# LichenDR — Fase 1

Mockup interactivo del prototipo de biomonitoreo de líquenes para la República Dominicana.

## Ejecutar en GitHub Codespaces

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Cuando Codespaces muestre la notificación del puerto, selecciona **Open in Browser**.

## Qué incluye

- Flujo navegable de nueve pantallas.
- Carga y previsualización temporal de imágenes JPG/PNG.
- Revisión simulada de metadata.
- Ubicación manual y mapa.
- Formulario de árbol, sustrato y contexto.
- Demostración visual de un conteo de 50 puntos.
- Resultado provisional con límites científicos.
- Lista de observaciones ficticias.
- Descarga de un CSV de demostración.

## Qué todavía no incluye

- Lectura real de EXIF/GPS.
- Base de datos o almacenamiento permanente.
- Clasificación editable de los puntos.
- Identificación de especies.
- Estimación ambiental validada.

Los registros marcados como demostración son ficticios. La cobertura mostrada en esta fase no debe utilizarse como un resultado científico.
